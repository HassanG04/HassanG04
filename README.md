## Selected work

### [Flood Detection](https://github.com/HassanG04/River-Flood-Prediction)

Satellite-image segmentation pipeline using a lightweight U-Net variant. Reached 0.741 validation mIoU on 306 labeled image-mask pairs.

### [Heart Disease Prediction](https://github.com/HassanG04/yet_another_heart_disease_application)

Leakage-controlled, multi-hospital ML pipeline with MICE imputation, Optuna tuning, calibrated decision thresholds, stacking, and SHAP explanations. Reached 0.92 AUC and 85% recall on held-out data.

### [Twitter Emoji Predictor](https://github.com/HassanG04/Emoji_Recognition)

Fine-tuned DistilBERT for multiclass emoji prediction and deployed it through Django for real-time inference. Improved test accuracy from a 71.6% TF-IDF baseline to 93.1%.

### [Shoplifting Detection](https://github.com/HassanG04/ShopLifting_Detection)

CCTV-video pipeline combining YOLOv8 person and action detection with MobileNetV3-Small and BiGRU temporal classification, supported by strict train-validation-test separation.

### [Cancerous Cell Detection](https://github.com/HassanG04/cancer_cell_detection)

Validated 220,025 labeled images, removed 1,645 low-quality samples, and trained a ResNet18-ViT ensemble that reached 96.21% validation accuracy.
